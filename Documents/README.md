## 当前实现基线

- Android 工程：Gradle Kotlin DSL，主模块为 `app`。
- 主入口：`MainActivity`，当前采用单 Activity + XML 布局 + 动态牌面视图。
- 核心分层：`model` 保存数据，`rule` 识别和比较牌型，`controller` 推进牌局，`ai` 选择出牌，`network` 做蓝牙房间和消息同步。
- 本地模式：1 名本地玩家 + 3 个 AI 托管。
- 联机模式：房主为 `p1`，`p2` / `p3` / `p4` 可配置为蓝牙真人或 AI 托管，房主选择的南方/北方规则会同步给客户端。
- 测试入口：`app/src/test/java/com/scut/chudadi` 下覆盖规则、控制器、蓝牙消息编解码和牌面传输编码。

## 文档维护约定

1. 规则变化先更新规则文档，再补测试，最后调整 README 摘要。
2. 蓝牙协议字段变化后，同步更新 `蓝牙联机测试记录.md` 和 `BluetoothMessageCodecTest`。
3. 新增外部素材必须先补 `资源授权说明.md`，再提交资源文件。
4. UML 图片若与代码结构偏差较大，优先在 `UML Graphs/README.md` 中标注适用范围，再决定是否重画。
